# Speedrun-Lab-UI
Can visualize MCSR Ranked Runs using Unity Engine 6

Is an extension to:
https://github.com/kanes48/RankedMatchAnalyser

Requires a json in the format, which is provided by RankedMatchAnalyser.
Is only a standalone script, requires some setup in Unity:
- Create empty game object to add the script onto
- Create a basic project layout in the ```Assets/``` folder (```Scripts/```, ```StreamingAssets/```)
- Import the json into ```StreamingAssets/```
- Import the scripts into ```Scripts/```
- Add the provided sound to the Main Script
- Customize as needed

Version:
UnityEditor 6.X
