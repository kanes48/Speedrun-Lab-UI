# Speedrun-Lab-UI
Can visualize MCSR Ranked Runs using Unity Engine 6

Is an extension to:
https://github.com/kanes48/RankedMatchAnalyser

Requires a json in the format, which is provided by RankedMatchAnalyser.
Is only a standalone script, might require some setup in unity (Adding and Event System and an Empty, etc...)

Version:
UnityEditor 6.X
